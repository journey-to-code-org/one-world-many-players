# Security policy

One World, Many Players is a teaching server bound to localhost by default. It does not provide authentication, encryption, authorization, production deployment, or protection against hostile clients.

Do not expose it to an untrusted network as a production service.

Report dependency or implementation vulnerabilities through GitHub's [private security advisory form](https://github.com/journey-to-code-org/one-world-many-players/security/advisories/new). Ordinary tutorial corrections and localhost-only crashes may use Issues.
